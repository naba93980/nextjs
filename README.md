## Next.js

### About

A hands-on learning repository covering Next.js concepts - routing system, rendering strategies, authentication approaches, API routes, and styling. The examples are organized by topic, providing a reference for understanding different Next.js features and how they are used in web applications.

### Topics Covered

- **Getting Started** — creating a basic Next.js application
- **Routing** — pages, nested routes, dynamic routes, catch-all routes, and navigation
- **Pre-rendering and Rendering Strategies** — client-side rendering (CSR), server-side rendering (SSR), and static site generation (SSG)
- **Incremental Static Regeneration (ISR)** — understanding how statically generated pages can be revalidated
- **Data Fetching** — client-side data fetching and server-side data fetching patterns
- **API Routes** — creating API endpoints using Next.js
- **Authentication** — exploring NextAuth.js and server-side authentication patterns
- **Styling** — applying styles within Next.js applications
- **Miscellaneous Concepts** — additional Next.js features and experiments


### Getting Started

#### Prerequisites

- Node.js and npm
- Basic knowledge of JavaScript and React

#### Clone the Repository

```bash
git clone https://github.com/naba93980/nextjs.git
cd nextjs
```

Navigate to an individual example directory, install its dependencies using `npm install`, and run the appropriate script defined in that example's `package.json`.

## Purpose

This repository serves as a learning reference for understanding Next.js fundamentals and exploring different approaches to routing, rendering, data fetching, and authentication.
